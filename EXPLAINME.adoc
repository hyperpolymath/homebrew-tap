= homebrew-tap -- EXPLAINME

== "Homebrew formulae for hyperpolymath tools"

[quote, Formula/boj-server.rb]
____
Cartridge-based MCP server with 53 formally verified domain cartridges.
____

This tap provides `brew install` access to hyperpolymath CLI tools.
Currently ships a single formula for
https://github.com/hyperpolymath/boj-server[boj-server].

**Caveat:** The formula references a release tag (`v0.3.1`) whose tarball
SHA-256 is not yet pinned (marked `UPDATE_ON_RELEASE`).

[cols="1,2", options="header"]
|===
| Path | Proves

| `Formula/boj-server.rb`
| Homebrew formula: install, test, and dependency declarations for boj-server

| `contractiles/`
| Contractile validation rules for the tap
|===
