== What this is

This is the official https://brew.sh[Homebrew] tap for hyperpolymath
tools. It lets macOS (and Linux) users install hyperpolymath binaries
via `+brew+` without manual compilation.

== Install

[source,bash]
----
# Add the tap once
brew tap hyperpolymath/tap

# Install BoJ server (cartridge-based MCP server)
brew install boj-server
----

== Notes for maintainers

The `+boj-server.rb+` formula contains a `+sha256+`
`+"UPDATE_ON_RELEASE"+` placeholder that must be replaced with the
actual tarball SHA-256 when cutting a release. Run `+sha256sum+`
`+<tarball>+` or use `+brew+` `+fetch+` `+--build-from-source+` to
obtain it.

See EXPLAINME for the full implementation map.
